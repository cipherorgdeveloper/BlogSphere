# Project Guidelines & Rules for BlogSphere

## Pull Request Default Target
Whenever the user asks to create or send a Pull Request (PR), always target the upstream repository `https://github.com/BlogSphere/BlogSphere` from the user's fork `pateldeep04/BlogSphere`.
- Upstream Target Repo: `BlogSphere/BlogSphere`
- User Fork Repo: `pateldeep04/BlogSphere`
- Default Cross-Fork PR Link Format: `https://github.com/BlogSphere/BlogSphere/compare/main...pateldeep04:BlogSphere:<branch_name>?expand=1`
